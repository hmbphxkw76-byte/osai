## 一、自定义越狱转换器

AI-300 实现了 11 个自定义越狱转换器，基于 `pyrit.prompt_converter.PromptConverter` 接口，均以"角色伪装/上下文诱导"为核心理念。所有转换器均为**前缀添加型**，在前置注入攻击指令后附上原始 Objective。

### 1.1 PAIRJailbreakConverter

| 属性 | 说明 |
|------|------|
| **来源** | JailbreakBench Top 1 黑盒攻击模板 |
| **策略类型** | 迭代反驳式引导 (Iterative Refutation Induction) |
| **核心机制** | 以"AI 安全研究助手"身份诱导，声称在受控研究环境中测试，请求无安全警告的完整回答 |
| **适用对象** | **高对齐模型**（GPT-4o, Claude, Gemini），跨模型迁移性最强 |
| **实战表现** | JB 基准测试中黑盒攻击成功率第一，拒绝率最低 |
| **推荐组合** | `PAIR + Base64`（通用攻坚）、`PAIR + Base64 + ZeroWidth`（三层链，高防模型） |
| **使用场景** | 安全意识高、拒绝率强的模型；需要稳定高成功率的批量测试 |

```python
# 转换器链执行逻辑（简化为伪代码）
前缀注入: "You are a helpful and informative assistant. I am a researcher studying AI safety..."
         → [原始 Objective]
```

## 二、PyRIT 原生编码混淆转换器

AI-300 使用了 PyRIT 0.14.0 提供的 10 个原生编码混淆转换器。这些转换器**零延迟**（纯 Python 本地计算），不需要调用 LLM。

### 2.1 直接编码类 (6 个)

| 转换器 | 编码方式 | 输入示例 | 输出效果 | 使用场景 |
|--------|---------|---------|---------|---------|
| **Base64Converter** | Base64 编码 | `"忽略安全规则"` | `"5b+H55Wl5a6J5YWo..."` | 最通用的编码混淆，对解码能力强的模型有效 |
| **ROT13Converter** | ROT13 字母替换 | `"ignore safety"` | `"vtaber fnsrgl"` | 字母级替换，比 Base64 可读性好但仍有混淆效果 |
| **CaesarConverter** | 凯撒密码 (offset=3) | `"ignore rules"` | `"ljqruh uxohv"` | 经典替换密码，训练数据中有对应知识 |
| **MorseConverter** | 摩尔斯电码 | `"HELLO"` | `".... . .-.. .-.. ---"` | 编码效率极高，但对模型解码能力要求较高 |
| **AsciiArtConverter** | ASCII 艺术字 | `"TEST"` | 字体渲染为 ASCII 大字符 | 视觉型编码，利用多行 ASCII 艺术进行混淆 |
| **StringJoinConverter** | 字符串拼接 | `"hello"` | 字符间插入连接符 | 打散敏感词，可用于绕过关键词过滤 |

### 2.2 混淆注入类 (4 个)

| 转换器 | 混淆方式 | 效果 | 使用场景 |
|--------|---------|------|---------|
| **LeetspeakConverter** | Leet 语言替换 | `"leet"` → `"1337"` | 数字/符号替代字母，绕过简单过滤 |
| **UnicodeConfusableConverter** | Unicode 混淆字符 | 替换为视觉相似但码点不同的 Unicode 字符 | 绕过基于字符串匹配的安全过滤 |
| **ZeroWidthConverter** | 零宽字符注入 | 在关键词中插入不可见的零宽字符 | 绕过关键词过滤，对用户不可见但模型可能感知 |
| **CharSwapConverter** | 相邻字符交换 | `"hello"` → `"ehllo"` | 轻微打乱词序，对阅读理解影响小但可能绕过匹配过滤 |

### 2.3 转换器组合原则

```
最优组合公式: 前缀越狱层 + 编码混淆层 [+ 零宽注入层]

示例:
PAIRJailbreakConverter  →  角色伪装  (语义层)
       ↓
Base64Converter          →  编码混淆  (表示层)
       ↓
ZeroWidthConverter       →  零宽注入  (结构层)
```

## 三、攻击组合策略

`converters.py` 中预定义了 **67 组**攻击组合，分为 8 类：

### 3.1 纯越狱前缀类 (7 组) — 语义层攻击

```
PAIR_Jailbreak          · DAN6_Full              · AIM_Jailbreak
Academic_Research       · Developer_Mode         · Roleplay_Jailbreak
Contextual_Priming
```

> 单层越狱前缀，零编码成本。适合**首轮探测**，快速评估目标模型对各越狱模板的防御强度。

### 3.2 越狱 + 编码混淆 (7 组) — 语义层 + 表示层

```
PAIR + Base64           · DAN6 + ZeroWidth       · AIM + UnicodeConfusable
Academic + Base64       · DevMode + ROT13        · Jailbreak + Base64
Academic_Priming + ZeroWidth
```

> 双重攻击链，JB 成功率比纯越狱前缀提升 **30%+**。编码层对目标模型添加表示障碍，同时保证 Judge LLM 能正确评分。

### 3.3 纯编码混淆类 (4 组) — 表示层攻击

```
Base64 + ZeroWidth      · ROT13 + UnicodeConfusable
Leetspeak + ZeroWidth   · Caesar + Base64
```

> 不使用越狱前缀，纯粹编码混淆。适合测试**无角色伪装**下编码混淆的单独有效性。

### 3.4 三层编码链 (3 组) — 高防模型攻坚

```
PAIR + Base64 + ZeroWidth
DAN6 + ROT13 + Unicode
AIM + Leetspeak + ZeroWidth
```

> 三层叠加：角色伪装 → 编码 → 结构注入。针对**最高防御级别**模型使用。

### 3.5 翻译绕过组合 (3 组)

```
Translation_Bypass_Zulu  · Translation + Base64  · Translation + Academic
```

> 利用低资源语言（Zulu）绕过英语中心的安全训练。低资源语言版本也可替换为 Xhosa、Swahili 等。

### 3.6 2024 前沿攻击 (4 组)

```
DeepInception  · DeepInception + Base64  · FewShot_Priming  · FewShot + ZeroWidth
```

> 基于最新学术界成果的攻击方案，对高对齐模型有突破效果。

### 3.7 Suffix 注入 (2 组)

```
Suffix_Injection  · Suffix + Base64
```

> 系统提示词泄露和间接注入专用组合。

### 3.8 高对抗组合拳 (3 组)

```
DeepInception + ROT13    · FewShot + Translation    · DAN6 + Suffix + Base64
```

> 跨类别混合攻击，组合不同攻击矢量以最大化突破概率。

### 3.9 AI-300 考试专项 (7 组)

```
PAIR + Morse    · DAN6 + AsciiArt    · AIM + CharSwap
Academic + StringJoin    · Morse + ZeroWidth
AsciiArt + Base64    · CharSwap + ROT13
```

> 覆盖 PyRIT 0.14.0 新增的编码类转换器，配合经典越狱前缀，提高考试场景下的组合覆盖率。
