# 2026-07-20 工作日志

## v3.7 全链路编排 + 凭据管理

### 完成内容

#### 1. CredentialManager（统一凭据管理器）
- 新建 `pyrit_ai300/pipeline/credential_manager.py`（480 行）
- `CredentialResolution` 数据类：封装凭据解析结果
- `CredentialManager` 类：
  - `resolve(target_url)` → 按域名匹配凭据文件 + JWT 过期检查
  - `resolve_or_none(target_url)` → 便捷方法
  - `for_garak(resolution)` → 环境变量格式
  - `for_deepteam(resolution)` → 请求头格式
  - `for_openai_target(resolution)` → api_key 格式
  - `for_http_target(resolution)` → Authorization 头
  - `for_playwright(resolution)` → AuthProfile 实例
  - `validate_with_http(resolution, target_url)` → HTTP 预检验证
  - `print_status(resolution)` → 终端友好格式显示
- JWT 过期缓冲：300 秒（5 分钟）
- 凭据目录：`config/targets/credentials/`

#### 2. Garak/DeepTeam 凭据注入
- `garak/adapter.py`：支持 `credential_bearer` 和 `credential_headers` 配置参数
  - Bearer Token → `OPENAI_API_KEY` 环境变量
  - Cookie → `OPENAI_API_KEY` 环境变量（降级方案）
- `deepteam/adapter.py`：支持 `credential_bearer` 和 `credential_headers` 配置参数
  - Bearer Token → `base_headers["Authorization"]`
  - Cookie → `base_headers["Cookie"]`
  - api_key 后备 → `base_headers["Authorization"]`

#### 3. PipelineOrchestrator（全链路编排器）
- 新建 `pyrit_ai300/pipeline/orchestrator.py`（580 行）
- `PipelineResult` / `PhaseResult` 数据类
- 四阶段编排：credential → recon → attack → report
- 每个阶段独立错误处理，失败不阻塞后续阶段
- Rich 格式化输出（阶段进度表 + 侦察结果表 + 攻击结果表 + 摘要）
- 便捷方法：`run_recon_only()` / `run_attack_only()`
- 凭据注入到侦察工具（`_inject_credentials_to_config`）
- 凭据注入到攻击目标（`_inject_credentials_to_attack`）
