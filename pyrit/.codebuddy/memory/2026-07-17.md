## litellm 版本锁定（10:30）

### 问题
garak 依赖 litellm>=1.84.0，但 litellm v1.91.0+ 引入了 Rust python-bridge 组件，Windows 上编译需 MSVC 工具链（link.exe），导致安装失败。

### 解决方案
在 pyproject.toml 的 recon 依赖中显式锁定 litellm 版本：
- `litellm>=1.84.0,<1.91.0` — 满足 garak 最低要求，同时避开 Rust 依赖
- 安装命令：`pip install -e ".[recon]"`（Windows/Kali 通用）

### 版本依据
- garak 要求：`>=1.84.0`
- Rust bridge 引入：v1.91.0（Rust OCR gateway）
- 安全区间：1.84.0 ~ 1.90.x
