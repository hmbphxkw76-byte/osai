## 移除步骤 3 自定义目标选项

### 原因
- config 是唯一配置源，自定义目标绕过这个原则
- 自定义目标只提供 {goal}，不加载 {name} {email} 等占位符，导致模板不完整
- 如需自定义，直接编辑 config/placeholders/ 下的文件

### 改动
- 删除 "c" 自定义目标选项（输入提示 + 处理逻辑）
- 步骤 3 现在只有两个操作：Enter = 加载全部配置，q = 退出
