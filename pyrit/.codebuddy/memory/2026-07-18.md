### 关键架构理解

#### 1. v3.0 架构核心
- SmartMatcher = 策略选择器（不执行，只选择 PyRIT 攻击类）
- AttackOrchestrator = PyRIT 攻击构建器 + 结果收集器
- 执行全部交给 PyRIT 原生攻击（继承重试/升级/回退/剪枝/早停）

#### 2. 侦察-攻击解耦
- reconnaissance/ 不 import attack/
- 通过 TargetProfile JSON 文件通信
- 支持 AIMAP→Garak 顺序侦察整合

#### 3. 智能编码选择器（v1.0）
- 第1级：OWASP 类别静态过滤
- 第2级：语言兼容性过滤（CJK 排除拉丁编码）
- 第3级：目标自适应探测（运行时）

#### 4. 占位符系统（v2.0）
- Tier 1：`{goal}` / `{objective}` — `_goals.yaml`
- Tier 2：14种编码变体 — 自动从 objective 编码
- Tier 3：50+ 领域参数 — 模板 `placeholders:` 自声明

#### 5. 流水线追踪
- 全链路：recon → load → normalize → classify → strategy → execute → scoring
- 编码选择三阶段追踪：owasp_filter → language_filter → probe → selection

#### 6. 认证系统（NEW）
- `header_parser.py` 支持 Bearer/Cookie/组合认证
- JWT Token 过期时间解析
- `playwright_injector.py` 浏览器上下文注入认证

#### 7. 速率控制（NEW）
- 并发控制：Semaphore + rate_limit
- 目标类型智能默认值：ollama=2, openai=5, http=3, playwright=1

#### 8. 报告格式（更新）
- Detailed Findings: Finding #1 / #2... 含 OffSec 标准字段
- 标题自动生成（中文映射）
- 严重度：catalog 优先 > 成功率推算
- Evidence 不截断，无前缀标签
