## 用户需求

搜索 LLM 红队/越狱（LLM Red Teaming, Jailbreak, Prompt Injection）相关最新技术资料，优先搜索 arxiv.org，然后搜索 github.com，将搜索结果整理后写入三库。

## 核心功能

1. 搜索 arxiv.org 获取 LLM 红队/越狱相关最新论文
2. 搜索 github.com 获取相关开源实现和项目
3. 整理搜索结果，提取关键信息（论文标题、作者、摘要、GitHub 仓库等）
4. 将整理后的资料写入三库：

- 开发规范 `docs/DEVELOPMENT.md`
- 规则库 `.codebuddy/rules/`
- 记忆库 `.codebuddy/memory/MEMORY.md`

## 技术方案

### 搜索策略

1. **arxiv 搜索**：使用 agent-browser 访问 arxiv.org，搜索关键词包括：

- "LLM red teaming"
- "jailbreak"
- "prompt injection"
- "AI safety evaluation"

2. **GitHub 搜索**：使用 agent-browser 访问 github.com，搜索相关开源项目：

- LLM red teaming tools
- Jailbreak frameworks
- Prompt injection datasets

### 写入三库格式

- **开发规范**：新增「参考资料」章节，列出关键论文和项目
- **规则库**：新增 `research-references.md` 规则文件，编号 RES-001
- **记忆库**：新增「LLM 红队研究资料」章节，记录搜索日期和关键发现

### 工具使用

- 使用 `[skill:agent-browser]` 进行网页搜索和内容提取
