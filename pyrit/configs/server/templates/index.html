💡 专家提示
  • AI 安全训练靶机 (AISecLab)：通常默认密码为 training-admin / training-key，登录后 Cookie 格式为 lab_session=...。
  • 多格式 API 兼容：部分靶机同时支持 OpenAI + Anthropic + Gemini 格式，建议使用「多格式探测」发现所有攻击面。
  • Debug 端点：靶机常故意暴露 /debug/info、/debug/config 等端点，可用于信息收集。
  • robots.txt：AI 训练平台常在 robots.txt 中列出内部路径（如 /internal、/admin），是重要的侦察信息源。
  • 限速处理：大部分 AI 服务的 API 有请求频率限制（常见 30/min），后续攻击需控制并发。
  • 先认证后探测：认证后的探测能发现更多端点（401/403 会误报为不存在），建议先完成步骤 2 再开始步骤 3。

第二步 · 配置认证

2 / 4
系统将先自动检测目标是否需要认证。请勿进行账户爆破 — 通过浏览器登录后在开发者工具复制对应字段即可。所有字段值会自动保存到 configs/tokens/，后续步骤自动读取最新值。
通常与步骤 1 一致。如登录页是单独子路径（如 /login），可填写登录页地址。
系统将直接以 name=value; name=value 格式作为 HTTP Cookie 请求头原样发送
📋 从哪里获取
  1. 浏览器打开目标网站并登录
  2. 按 F12 → Network（网络） 标签
  3. 刷新页面，点击任意一个请求
  4. 右侧 Request Headers 中找到 Cookie: 一行
  5. 复制冒号后面的全部内容
✅ 正确 lab_session=gAAAAABqTxfepOgzhajjg-xQZdQ...
✅ 正确 lab_session=xxx; user_role=admin; token=abc
❌ 错误 "lab_session=xxx" — 不要加引号，" 只是 Python/JS 的字符串定界符
❌ 错误 gAAAAABqTxfepOgzhajjg-xQ... — 缺少 lab_session= 键名，服务器无法识别
💡 技巧 多个 Cookie 用分号空格分隔：; （不要用逗号或换行）
📋 适用场景

目标首页是登录页面（如 Gradio 应用、内网 AI 平台），系统会自动：

  1. 解析登录表单的用户名/密码字段
  2. 提交登录请求（密码仅存在于内存，不落盘）
  3. 捕获登录成功后返回的 Set-Cookie、Authorization 等凭证
  4. 自动保存为 Cookie / JWT / API Key
💡 建议 如果已知 Cookie/Token，直接用左侧 Cookie 或 JWT 模式粘贴更快
⚙️ 高级字段（已自动填充）▾
系统会自动添加 Authorization: Bearer <你的JWT> 请求头
📋 从哪里获取
  1. 浏览器 DevTools → Application（应用） → Local Storage / Session Storage，搜索 token / jwt / access_token
  2. 或者 Network → 任意请求 → Request Headers → Authorization: Bearer eyJ...，复制 Bearer 后面的 部分
✅ 正确 eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJzdWIiOiIxMjM0...
❌ 错误 Bearer eyJhbGciOiJIUzI1NiIs... — 不要包含 Bearer 前缀，系统会替你加
❌ 错误 "eyJhbGciOiJIUzI..." — 不要加引号
💡 注意事项 JWT 由 3 段 base64 组成，以 . 分隔。如果只有 2 段或包含空格/换行，说明复制不完整
系统会自动添加 Authorization: Bearer <你的API Key> 请求头
📋 从哪里获取
  1. 服务方提供的管理后台 / API Keys 页面
  2. 浏览器 DevTools → Network → 任意 API 请求 → Request Headers → Authorization: Bearer sk-xxx，复制 Bearer 后面的 部分
✅ 正确 sk-proj-AbCdEf1234567890abcdef
✅ 正确 gsk_xxxxxxxxxxxxxxxxxxxxxxxxxxx
❌ 错误 Bearer sk-xxx — 不要含 Bearer 前缀
❌ 错误 Authorization: Bearer sk-xxx — 不要含整个 Authorization 字段
💡 常见格式 OpenAI: sk-proj-xxx · Google: AIzaSy... · GitHub: ghp_xxx · 其他服务通常为随机字符串
