## Auth 认证信息加载与展示功能

### 新增功能
在 header 加载后增加详细的认证类型识别与展示能力：

1. **AuthContext.auth_type 属性** (`models.py`)
   - 自动识别认证类型：jwt, jwt+cookie, jwt+api_key, bearer, cookie, basic, api_key, none 等组合
   - 通过 JWT 三段式格式检测，不依赖外部库

2. **JWT 解码** (`auth_parse.py`)
   - `is_jwt(token)`: 检测 token 是否为 JWT 格式
   - `decode_jwt(token)`: 无签名验证的 JWT header/payload 解码（base64url）
   - 适合红队侦察场景下快速理解认证上下文

3. **Basic Auth 编码** (`auth_parse.py`)
   - `encode_basic_auth(username, password)`: 编码为 HTTP Basic Auth 凭据

4. **describe_auth(auth)** (`auth_parse.py`)
   - 生成详细认证描述输出，包含：
     - 认证类型中文标签
     - Cookie 数量和名称列表
     - JWT header 和 payload 解码（敏感字段 sub/email/name 自动脱敏）
     - JWT 过期时间检测
     - Basic Auth 用户名和编码凭据
     - API Key 头名称和值预览
     - 检测 extra_headers 中 Base64/URL 编码的账户密码信息

5. **summarize() 更新**：返回值增加 `auth_type` 字段

### Bug 修复
- **cli.py wizard 路径**：修复了 `auth = None` 导致认证信息在 recon_phase 后丢失的问题，现在 wizard 预解析 auth 并传递给所有后续攻击阶段（injection, agent, rag, embeddings, supply_chain）
