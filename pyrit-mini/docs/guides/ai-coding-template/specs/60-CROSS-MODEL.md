## 审查策略（政策阈值）
| 变更级别 | 模型数 | Cohen's κ 阈值 | 仲裁 |
|---------|-------|----------------|------|
| P0 核心 | 全部 | ≥ 0.75 | Tier3 人工 |
| P1 支撑 | ≥ 2 | ≥ 0.60 | Tier2 升级 |
| P2 辅助 | ≥ 1 | ≥ 0.50 | Tier1 合并 |

> κ 衡量“审查结论一致度”（分类）；Pearson r 衡量“产物输出相似度”（连续，C13 用 r ≥ 0.85）。二者不互换。

## 触发条件
- P0 核心变更 ✅ / 新增依赖 ✅ / 安全变更 ✅ / 跨地区协作 ✅
- P2 辅助 ❌（可选） / 文档更新 ❌

## 三级仲裁（度量绑定见 ai-dev-audit.md §5.4）
- Tier1：κ ≥ 0.60 → 自动合并
- Tier2：0.40 ≤ κ < 0.60 → 升级第三方模型
- Tier3：κ < 0.40 → 人工仲裁
