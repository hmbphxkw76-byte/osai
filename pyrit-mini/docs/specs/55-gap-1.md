## 2. 缺口 1: 输出过滤器绕过 [sid:55-gap1-filter]

### 2.1 概述

针对 LLM 输出端安全过滤器的绕过攻击模块。基于 ASR 动态选择四种 PyRIT 原生攻击策略，覆盖从单轮到迭代的多种绕过场景。

**实施落点**：`strike/output_filter_bypass.py`（流水线集成见 `core/phases/strike.py` `_run_advanced_attacks_phase`）

### 2.2 学术理论基础

| 技术 | 论文 | ASR | 机制 |
|------|------|-----|------|
| Many-Shot Jailbreaking | arXiv:2402.05124 (Anthropic) | 60-80% | 利用长上下文窗口填充大量jailbreak示例 |
| Chunked Request Attack | PyRIT Native | 40-60% | 将敏感请求分块绕过token级过滤 |
| Cross-Domain Prompt Injection (XPIAA) | PyRIT Native | 50-70% | 通过跨域上下文注入绕过输出过滤器 |
| Red Teaming Attack | PyRIT Native | 55-75% | 使用对抗性LLM迭代优化payload |

### 2.3 策略选择逻辑

| ASR 区间 | 策略 | 原理 |
|----------|------|------|
| < 20% | ManyShotJailbreakAttack | 最高单轮提升 |
| 20-35% | ChunkedRequestAttack | 绕过token过滤器 |
| 35-50% | XPIAAttack | 跨域注入 |
| 50-65% | RedTeamingAttack | 迭代优化 |
| ≥ 65% | 无需绕过 | — |

> **代码 SSOT**：策略阈值与实现以 `strike/output_filter_bypass.py` 的 `determine_bypass_strategy()` 与 `run_output_filter_bypass()` 为准。
